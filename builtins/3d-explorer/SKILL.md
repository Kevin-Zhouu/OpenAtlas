# 3D explorer
Use 3D only when spatial relationships are essential to understanding. Bundle Three.js and any assets locally in the artifact. Start with a comprehensible camera angle, constrain orbit controls, offer reset view, and provide named view buttons. Label important structures and use color plus text. Add cutaways, isolation controls, or stepwise motion when these serve the lesson. Provide an SVG or prose fallback for unavailable WebGL. Never require a remote CDN or external asset fetch. Keep the scene lightweight for phones and pause animation when offscreen. Test view/reset controls and visible accompanying explanations in Chromium. Do not claim that a decorative 3D model is anatomically or physically exact.
